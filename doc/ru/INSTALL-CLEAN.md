# Magic Lantern RU — 2026-10-28_5D2_ru.212

Русификация dimalishes на базе Magic Lantern ed3e7c0dfacfdeaf3349dee73edf9e3621217462.
**Только Canon EOS 5D Mark II с Canon firmware 2.1.2.**
Не для 5D, 5D Mark III и других версий прошивки. Обновления самой прошивки
Canon до 2.1.2 в комплекте нет. Точный целевой порт: 5D2.212.

Включены русские меню и подсказки, шрифты, 206 русских и 204 английские
страницы справки, исправленные переходы INFO, остановка интервалометра
в режиме 0 с и исправления наложений «ГБ» и данных объектива.
Бинарник и таблица символов собраны вместе для 5D2.212. Входящие 19 модулей —
набор этого порта; включение всех модулей для установки не требуется.
Новые описания функций, отсутствовавшие в руководстве, не добавлялись.
Часть надписей внутри исходных иллюстраций справки остаётся английской.

Стартовый текст изменён по варианту dimalishes; имя сборщика — dimalishes.
Частота показа стартового предупреждения сохранена: повторно оно может
не появиться, если уже подтверждено в тот же день по часам камеры.

Язык: Настройки → Язык меню / Prefs → Menu language.
Delete открывает ML; INFO — справку пункта; Справка → Полная справка — главы.
Стрелки/диски листают справку, INFO или SET возвращает в меню.

Лицензии: COPYING и ML/fonts/DejaVu-LICENSE.txt. Исходники находятся в этом репозитории; сборка описана в BUILD-RU.md.
Сохраняйте их при публикации. Оригинальные предупреждения и авторство ML
сохранены в ML/README и исходниках.

## Чистая установка ML

Этот вариант содержит оригинальный ML-SETUP.FIR именно из платформы
5D2.212 исходного архива ML. Он не русифицировался и не пересобирался.
Он запускает установщик ML и настраивает загрузку с карты; это не пакет
обновления Canon до 2.1.2. Копирование одного autoexec.bin на чистую карту
само по себе не делает её загрузочной.

1. Проверьте модель и Canon firmware 2.1.2. Зарядите аккумулятор, выберите M.
2. Сохраните файлы CF-карты на компьютер. Для первой установки исходное
   руководство рекомендует обычную CF до 32 ГБ включительно.
3. Отформатируйте CF в камере: это удалит данные карты.
4. При выключенной камере скопируйте весь комплект в корень карты:
   autoexec.bin, ML-SETUP.FIR и папку ML. Не оставляйте их во вложенной папке.
5. В меню Canon откройте пункт версии прошивки и запустите обновление ПО
   с этой карты. Следуйте экранным указаниям установщика ML. Не прерывайте
   работу до появления экрана успешной установки с предложением перезапуска.
6. После подтверждения установщиком выключите и включите камеру.
7. Нажмите Delete, чтобы открыть ML. Проверьте язык меню и INFO-справку.

Архив не содержит прежних настроек пользователя. По умолчанию выбран русский,
интервалометр выключен. Модули автоматически не включайте для первого теста.
Не удаляйте один autoexec.bin с загрузочной карты: для возврата к исходной
работе используйте другую обычную карту без ML. Полное отключение загрузки ML
в камере выполняется штатным установщиком по его экранным указаниям.
После открытия крышки карты дождитесь окончания обращения к ней и ещё
не менее 5 секунд перед извлечением — это требование исходного руководства.

Выполнены проверки в QEMU. Затем владелец подтвердил полное удаление ML
и успешную установку с нуля на чистую карту на Canon EOS 5D Mark II / 2.1.2.
