# Русская справка Magic Lantern

Переведены 11 исходных документов, 128 разделов. Тексты: файлы MANUAL.txt,
MN-*.txt и EPILOGUE.txt в этом каталоге; полный текст: full-help-ru.rst.

Из корня репозитория запустите `python3 tools/ru-help/render.py`.
Генератор создаёт doc/cam/ru (206 страниц) и doc/cam/en (204 страницы),
индексы menuidx.dat и src/menuindexentries.h.
Привязки: tools/ru-help/menu-aliases.json.

INFO открывает справку пункта, Справка → Полная справка — оглавление;
стрелки/диски листают, INFO/SET возвращают в меню.
Переходы используют исходные английские ключи меню.
Новые описания для отсутствующих в оригинале разделов не добавлялись.
Руководство историческое и описывает несколько моделей: не все функции
доступны на 5D Mark II. Надписи внутри исходных иллюстраций могут быть английскими.

Информация о проверке текущего выпуска: README-RU.md в корне репозитория.
