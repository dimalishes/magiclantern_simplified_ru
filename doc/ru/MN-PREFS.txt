Настройки просмотра снимков

```````````````````````````
Настройка режима просмотра и воспроизведения.

.. _SET+MainDial:

SET + основной диск
"""""""""""""""""""

.. figure:: ../Compare_and_hdr.png
    :align: center
    :width: 7cm

При удержании ``SET`` и вращении основного диска ML выполняет выбранное действие:

* **Просмотр 422** — бесшумные снимки из ``DCIM/100CANON``; только низкое разрешение.
* **Слияние экспозиций** — объединение двух и более снимков для предпросмотра `HDR <HDR_>`__ или мультиэкспозиции.
* **Сравнение снимков** — сравнение двух кадров с диагональным разделением. Текущий снимок всегда оказывается сверху.
* **Просмотр таймлапса** — быстрая последовательная смена всех снимков.

.. _Change image review mode to PLAY:

.. _Image review:


Просмотр после съёмки
"""""""""""""""""""""

* **Обычный QuickReview** — как в штатной прошивке.
* **Удержание → PLAY** — если в меню Canon для просмотра после съёмки выбрано удержание, вместо QuickReview открывается полноценный ``PLAY``. Можно сразу увеличивать снимок, не нажимая ``PLAY`` отдельно. Авторы благодарят Кена Роквелла за подсказку `«Нужно нажать PLAY» <http://www.kenrockwell.com/canon/5d-mk-ii.htm>`__.

.. _Quick Zoom:


Быстрое увеличение
""""""""""""""""""

Ускоренное увеличение при просмотре для проверки точности фокусировки:

* **ВЫКЛ**.
* **ВКЛ — быстрое увеличение** — быстрее, чем в штатной прошивке Canon.
* **Одно нажатие → 100%** — ``Zoom In`` сразу увеличивает центральную область до 100%. Следующее нажатие возвращает весь снимок.
* **Максимум по точке AF** — аналогично, но по выбранной точке автофокуса.
* **Максимум по последнему положению** — запоминается прежнее положение увеличенной области.

Кнопка LV
"""""""""

Действие кнопки LiveView в режиме ``PLAY``:

* **По умолчанию** — переход в LiveView.
* **Защита снимка**.
* **Оценка снимка**.

.. _LiveView Zoom Settings...:


Настройки увеличения LiveView
`````````````````````````````

Настройка штатного увеличения Canon 5×/10×:

* **Увеличение 5×, 10×** — один из вариантов можно отключить. Тогда первое ``Zoom In`` увеличит изображение, второе вернёт общий вид.
* **Автоэкспозиция при увеличении** — автоматическая подстройка яркости увеличенного изображения. Позволяет менять диафрагму ручного объектива без чрезмерного затемнения или осветления экрана, облегчая фокусировку.
* **Повышение резкости и контраста** — при увеличении оба параметра максимальны. Повышенная резкость работает примерно как выделение резких контуров.
* **Увеличение по полунажатию** — включается при полунажатии спуска.
* **Увеличение по кольцу фокуса** — если объектив Canon сообщает дистанцию фокуса, вращение кольца включает увеличение. Чтобы оно оставалось дольше, удерживайте полунажатие спуска.

Быстрые действия стрелками и SET
````````````````````````````````

Выбор параметров для быстрой настройки стрелками:

* Усиление звука.
* ISO и ББ в кельвинах.
* Выдержка и диафрагма.
* Яркость дисплея и насыщенность.

Для SET можно дополнительно включить действия, соответствующие выбранной группе:

* Выбор аудиовхода: встроенный, внешний, балансный и другие.
* Настройка ББ по кнопке.
* Выдержка, соответствующая 180°, либо ближайшее доступное значение.
* Сброс яркости дисплея на 5 и насыщенности на обычную.

Действия датчиком дисплея
"""""""""""""""""""""""""

Датчик приближения у дисплея используется как дополнительная кнопка ML: для включения быстрых настроек стрелками, блокировки Follow Focus или обхода кнопки Magic Zoom.

Для полного отключения датчика в ML выключите ``LCD auto off`` в меню Canon, на первой вкладке с гаечным ключом. Это нужно, если установленное приспособление закрывает датчик, например экранная лупа.

.. _Sticky DOF Preview:


Фиксация предпросмотра ГРИП
"""""""""""""""""""""""""""

Кнопка предпросмотра ГРИП работает как переключатель: её больше не нужно удерживать.

Включённый предпросмотр ГРИП блокирует большинство других кнопок.

Совет: `«Принудительная экспозиция ML» <Exposure Override_>`__ позволяет просматривать ГРИП без блокировки кнопок.

Полунажатие спуска как переключатель
""""""""""""""""""""""""""""""""""""

Совет: позволяет не допустить автоматического выключения LiveView через 30 минут.

Быстрое цифровое увеличение на 600D
"""""""""""""""""""""""""""""""""""

Настройка сочетания ``DISP`` + ``Zoom In / Zoom Out`` в видеорежиме 600D/T3i:

* **1×, 3×** — переключение между 1× и 3× в FullHD.
* **3×…10×** — штатная плавная смена цифрового увеличения Canon от 3× до 10×.

По умолчанию ML **отключает увеличение свыше 3×**, чтобы избежать снижения качества.

Автоснижение качества серии
```````````````````````````

Временно снижает качество снимков в серийном режиме, чтобы сохранить приемлемую скорость при почти полном буфере.

Качество уменьшается, когда в буфере остаётся место менее чем для четырёх кадров:

* ``RAW+JPG`` → ``JPG Large Fine`` → ``JPG Medium Fine``.
* ``RAW`` → ``JPG Large Fine`` → ``JPG Medium Fine``.
* ``JPG Large Coarse`` → ``JPG Medium Coarse``.

Примеры результата из исходного руководства для 550D с Transcend Class 10; на другой карте результат может отличаться:

* ``RAW+JPG``, затем ``JPG-L``, все остальные ``JPG-M``.
* ``RAW``, затем ``RAW``, все остальные ``JPG-M``.

Энергосбережение LiveView
`````````````````````````

Настройки для увеличения времени работы от аккумулятора при LiveView.

* **Когда включать** — в ожидании, во время записи или всегда.
* **Использовать датчик дисплея** — взмах рукой будит камеру, а закрытие датчика на несколько секунд принудительно включает энергосбережение.
* **Приглушать дисплей** — при простое подсветка уменьшается до минимума.
* **Выключать дисплей и LV** — отключаются экран и работа матрицы LiveView, зеркало не перемещается. При видеозаписи или работающем детекторе движения выключается только экран; запись продолжается.
* **Выключать всю индикацию** — при простое графика ML скрывается, уменьшая нагрузку на процессор.

Файл настроек
`````````````

ML сохраняет настройки в ``MAGIC.CFG`` внутри ``ML/SETTINGS`` на карте. Подменю задаёт способ сохранения.

* **Автосохранение** — изменённые параметры меню автоматически записываются в ``MAGIC.CFG`` после закрытия меню.
* **Сохранить сейчас** — записать настройки ML в ``ML/SETTINGS/MAGIC.CFG``.
* **Удалить файл настроек** — возврат к настройкам ML по умолчанию. После удаления перезапустите камеру.

Наборы отображения LiveView
```````````````````````````

До четырёх наборов параметров вкладки `«Наложение» <Overlay_>`__.

На верхней панели показывается ``DISP`` 0, 1, 2 или 3 — номер текущего набора. Например, в ``DISP 0`` можно включить ложные цвета, в ``DISP 1`` — зебру и Focus Peak, а в ``DISP 2`` — кадрирующие рамки.

Пункт задаёт максимальное число наборов. Чтобы отключить функцию, оставьте один набор.

Для переключения нажмите ``INFO/DISP`` в LiveView либо ``[Q]`` на пункте «Вся индикация» вкладки «Наложение».

.. _Crop Factor Display:


Эквивалентное фокусное расстояние
`````````````````````````````````

Нижняя панель показывает фокусное расстояние в эквиваленте 35-мм кадра с учётом кроп-фактора 1,6×.

Например, объектив 50 мм f/1,8 отображается:

* ``50mm f/1.8`` — функция выключена.
* ``80eq f/1.8`` — функция включена.
