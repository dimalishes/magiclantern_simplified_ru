.. _contrast:

Контраст LiveView
`````````````````

Меняет контраст только на экране, не влияя на запись. Помогает фокусироваться с малоконтрастными стилями изображения.

Варианты: **Обычный** без изменений, **Высокий**, **Очень высокий**, **Низкий**, **Очень низкий**, **Нулевой**.

.. _saturation:

.. _LV saturation:


Насыщенность LiveView
`````````````````````

Меняет насыщенность только на экране, не влияя на запись. Позволяет сосредоточиться на фокусировке, не отвлекаясь на цвет.

Варианты: **Обычная** без изменений, **Высокая**, **Очень высокая**, **Нулевая — оттенки серого**.

.. _night vision:
.. _display gain:

.. _LV display gain:


Усиление изображения LiveView
`````````````````````````````

{{ nightdemo.jpg?200}}

Только для фоторежима. Повышает яркость LiveView в очень тёмных сценах, где штатное изображение Canon почти чёрное. Для лучшего результата в темноте можно сочетать с изменением FPS.

Диапазон: 0…+7 EV.

В видеорежиме похожего эффекта можно добиться цифровым ISO ML.

.. _Color scheme:


Цветовая схема
``````````````

Меняет цвет и яркость экранной информации, включая наложения LiveView, меню Canon и меню ML.

Варианты: **По умолчанию**, **Тёмная**, **Светло-серая**, **Тёмно-серая**, **Тёмно-красная**, **Тёмно-зелёная**.

Совет: тёмные схемы могут уменьшать нагрузку на глаза при ночной съёмке.

.. _Clean LiveView display:

.. _Clear overlays:


Скрывать индикацию
``````````````````

Убирает графические наложения с изображения LiveView.

* **Полунажатие** — удерживайте полунажатие спуска одну секунду. Можно также использовать ``*`` или кнопку предпросмотра ГРИП.

  Совет: назначьте автофокус на ``*`` через пользовательские функции Canon: ``Shutter/AE lock button`` = ``AE lock/AF``.

* **При простое** — вся индикация исчезает через несколько секунд после последнего нажатия, оставляя полностью чистое изображение.
* **Всегда** — индикация скрыта постоянно; меню работают как обычно.

  Может быть полезно с внешними рекордерами, поскольку скрывает рамку фокуса и другую графику.

.. _Focus box (LV):


Рамка фокуса в LV
`````````````````

Показывать рамку фокуса в LiveView либо скрывать её, когда она не нужна.

.. _Force HDMI-VGA:


Принудительный HDMI-VGA
```````````````````````

Включает низкое разрешение HDMI, 720×480, чтобы избежать чёрного экрана при начале и завершении записи.

.. _Screen layout settings...:


Настройки разметки экрана
`````````````````````````

Ориентация экрана, точное положение изображения и настройки внешних мониторов.

.. _Screen Layout:


Разметка экрана
"""""""""""""""

Выбор положения верхней и нижней информационных панелей ML для разных камер и внешних мониторов.

Две панели — сверху и снизу:

* **Внутри 3:2** — стандартно для камер с экраном 3:2, начиная с 550D.
* **Внутри 16:10** — для HDMI-мониторов 16:10.
* **Внутри 16:9** — для HDMI-мониторов 16:9.
* **Видео 4:3** — для 5D Mark II, 500D и 50D в видеорежиме.

Только нижняя панель:

* **Под 3:2** — для камер с экраном 4:3, например 500D, 50D и 5D Mark II, в фоторежиме.
* **Под 16:9** — для внешних мониторов низкого разрешения и камер с экраном 4:3 в видеорежиме.

Электронный уровень на 60D

Показывает положение кадра относительно горизонта. Работает и во время записи.

.. _Kill Canon GUI:


Скрыть интерфейс Canon
``````````````````````

Только для 50D. Выключает графику Canon, чтобы она не конфликтовала с графикой ML в LiveView.

* **Простой / меню** — графика Canon появляется только при открытии прозрачного меню LiveView.
* **Простой / меню + кнопки** — графика появляется также при нажатии кнопок и перемещении по прозрачным меню LiveView.
