# Magic Lantern RU alpha1 — Canon EOS 5D Mark II / firmware 2.1.2

Неофициальная экспериментальная локализация на базе исходного коммита
ed3e7c0dfacfdeaf3349dee73edf9e3621217462 (официальная dev-сборка 2025-06-20).
Собрана 2026-10-26, GCC ARM 10.3-2021.10. Не проверена на физической камере
и в QEMU. Успешная компиляция и проверки шрифтов не подтверждают работу камеры.

## Что сделано

362 записи перевода: основные разделы, многие пункты меню и значения,
часть звуковых подсказок. 66 букв кириллицы, включая Ё/ё, добавлены в шесть
RBF-шрифтов. Все исходные символы и их ширины сохранены побитно.
В Prefs / Настройки добавлен пункт Menu language / Язык меню:
English или Русский. По умолчанию включён русский.
Настройка хранится в обычной конфигурации ML под ключом menu.language.ru.

Внутренние имена меню, конфигурационные ключи, имена модулей и форматные
строки не переведены. Перевод применяется после форматирования только
к полным совпадающим экранным строкам. Поддержка произвольного UTF-8 в
скриптах не добавлена: шрифты используют локальную однобайтовую таблицу
160..225. Старые значки ML в позициях 128..159 сохранены.

## Ограничения alpha

Перевод неполный. Многие подсказки, динамические сообщения, составные
подписи MyMenu, сокращённый вид и меню модулей могут оставаться английскими.
На устройстве ещё нужно проверить загрузку, навигацию, переключение языка,
размеры окон, пересечения надписей и работу используемых модулей.
Макет ru-font-preview.png — проверка отрисовки шрифтов на компьютере,
а не снимок экрана работающей камеры.

## Как проверить на уже работающей установке ML

Архив обновления предназначен только для 5D Mark II с Canon 2.1.2 и уже
установленным ML. На компьютере заранее сохраните ВСЮ папку ML и
корневой autoexec.bin со своей карты. Предпочтительно использовать отдельную
тестовую загрузочную CF-карту с копией действующей установки.

Распакуйте содержимое magiclantern-5D2.212-RU-alpha1-update.zip в корень
такой карты с заменой совпадающих файлов. В комплект входят autoexec.bin,
шрифты, модули и файл символов от одной сборки. Папки ML/SETTINGS и
ML/LOGS в архив не включены. Новая установка ML и изменение bootflag
для этого обновления не нужны; установщик ML-SETUP.FIR в архив не включён.

После загрузки найдите Настройки → Язык меню. Английский вариант названия:
Prefs → Menu language. Проверьте обычный и расширенный вид, подменю,
Моё меню и используемые модули. Для возврата восстановите вместе исходный
сохранённый autoexec.bin и папку ML. Переключение языка само по себе
не возвращает исходную официальную сборку.

## Разработка и повторная сборка

Исходный архив: magiclantern-ed3e7c0.tar.gz. Изменения для него находятся
в magiclantern-RU-alpha1-changes.zip; распаковать поверх исходников.
Файлы *.rbf в пакете изменений уже сгенерированы.

Из корня исходников:

    python3 localization/generate.py
    python3 localization/verify.py
    make -C platform/5D2.212 -j4 ARM_BINPATH=/path/to/gcc/bin VERSION=RU-alpha1-ed3e7c0 zip_contents
    python3 localization/package.py

generate.py требует Pillow и шрифты DejaVu в /usr/share/fonts/TTF;
пути можно изменить в скрипте. Оригинальные буквы и значки берутся из
имеющихся файлов RBF. Генератор допускает повторный запуск.
verify.py требует исходный архив рядом с деревом исходников, gcc и Pillow.
Он сравнивает все исходные глифы и ширины, проверяет таблицу переводов,
переключение языка, запасной английский вывод, выбор шрифта и измерение
старших байтов при signed/unsigned char; создаёт ru-font-preview.png.

zip_contents собирает файлы без внешней утилиты zip. package.py формирует
архив Python и исключает установщик. Сборка без CONFIG_QEMU.
После изменения флагов компиляции следует выполнить make clean.
