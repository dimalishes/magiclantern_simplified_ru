# Исходники 2026-10-28_5D2_ru.212

Это исходный код и инструменты подготовки, не комплект для карты.
Цель — только platform/5D2.212 (Canon EOS 5D Mark II / Canon 2.1.2).
База: ed3e7c0dfacfdeaf3349dee73edf9e3621217462, изменения русификации dimalishes.
Сохранены COPYING и лицензии сторонних компонентов. Дампов ROM нет.

В репозитории: дерево Magic Lantern с применёнными правками, готовые RBF-шрифты,
русские тексты справки, исходные иллюстрации и генератор страниц/индексов.
Генерируемые страницы doc/cam не дублируются здесь: они есть в обоих
пакетах карты и могут быть заново созданы генератором.

Сборка из корня Git-репозитория:

    python3 tools/ru-help/render.py
    make -C platform/5D2.212 -j4 CROSS_COMPILE=/path/to/gcc-arm-none-eabi-10.3-2021.10/bin/arm-none-eabi- VERSION=2026-10-28_5D2_ru.212 ML_BUILD_USER=dimalishes zip_contents

Для render.py нужны Python 3, Pillow, docutils и DejaVuSans из
/usr/share/fonts/TTF или /usr/share/fonts/truetype/dejavu.
Для regenerate RBF при необходимости: python3 localization/generate.py
из корня дерева Magic Lantern. Для проверки: python3 localization/verify.py.
verify.py дополнительно требует исходный архив magiclantern-ed3e7c0.tar.gz
в родительском каталоге репозитория: это проверка сохранности исходных глифов, не условие сборки.

Проверенная цепочка — GNU Arm Embedded 10.3-2021.10; тулчейн отдельно не включён.
CONFIG_QEMU=n. Не применять сборку CONFIG_QEMU к физической камере.
Встроенное время сборки меняется; бинарное совпадение требует того же времени
и окружения. Метаданные выпущенных бинарников находятся в MANIFEST.json внутри установочных ZIP.

ML-SETUP.FIR для 5D2.212 — неизменённый предсобранный файл исходного архива ML.
В этой работе он не пересобирался. Его контрольная сумма и происхождение
записаны в манифесте чистой установки. Он есть также в исходной платформе.
Исходный общий установщик находится в src/installer.c; это не утверждение,
что современная пересборка побайтно воспроизводит старый предсобранный FIR.
